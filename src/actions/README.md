# Astro Actions

Folder ini disiapkan untuk action contracts ValueLoop.

Catatan sementara: pada Astro 6.4.x + `@astrojs/cloudflare` 13.x ada issue upstream ketika `src/actions/index.ts` dipakai bersama Cloudflare adapter. Gunakan API routes untuk scaffold awal, lalu aktifkan Actions setelah versi Astro/adapter yang dipakai sudah lolos `npm run build`.
